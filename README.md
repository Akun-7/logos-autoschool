# «ЛОГОС» автомектеби — сайт

Жалал-Абаддагы «ЛОГОС» автомектеби үчүн даяр сайт. Таза HTML/CSS/JS (серверсиз, китепканасыз). Тили: орусча жана кыргызча (RU/KY).

## Эмнелер бар

- Жогорку меню, тил которуу (RU/KY), мобилдик меню
- Hero + ыкчам жазылуу
- Мектептин артыкчылыктары (Instagram профилинен алынган маалыматтар)
- Курстар (категориялар), баасы config'тен
- **Пайызсыз бөлүп төлөө калькулятору** (графиги менен)
- Окуу тартиби (5 кадам), команда жана автопарк
- **ЖККЭ тренажёр**: машыгуу жана экзамен режими, түшүндүрмө, каталар боюнча иш, прогресс
- Пикирлер, сүрөттөр, инструкторлор, жакынкы топтор (config'тен, бош болсо көрүнбөйт)
- FAQ, байланыш, арыз формасы (текшерүү менен), карта, WhatsApp/телефон баскычтары
- SEO (meta, JSON-LD), жеткиликтүүлүк (клавиатура, aria), мобилдик адаптация

## Эмнени толтуруу керек: `js/config.js`

| Талаа | Эмне үчүн |
|---|---|
| `phone`, `phone2` | Телефон номерлери (чалуу баскычтары) |
| `whatsapp` | WhatsApp номери (`996700123456`), арыз ушул аркылуу келет |
| `formEndpoint` | (милдеттүү эмес) Formspree/Google Apps Script — арыздар автоматтык келет |
| `email` | Почта (арыз формасынын эң акыркы чарасы) |
| `hours` | Иш убактысы |
| `license` | Лицензия номери (сайттын түбүндө көрүнөт) |
| `categories[].price` | Курстардын баасы (сом); `enabled:true` — көрүнөт |
| `groups` | Жакынкы топтордун башталышы |
| `instructors`, `gallery`, `reviews` | Чыныгы инструкторлор, сүрөттөр, пикирлер |
| `logoImage` | Өз логотибиңиз (`assets/logo.png`) |

Сайтты өз компьютериңизде ачканда (localhost) мунун баары толтурулбай калганда жогору жакта сары эскертүү чыгат. Чыныгы сайтта ал көрүнбөйт.

**Маанилүү:** баалар, иш убактысы, лицензия жана пикирлер чыныгы болушу керек. Мен аларды ойлоп таппадым, ошондуктан алар бош.

## Ишке салуу (бекер)

1. Бүт `logos-autoschool` папкасын Netlify (drag & drop), GitHub Pages же Cloudflare Pages'ке жүктөңүз.
2. Өз доменинизди туташтырыңыз.
3. Локалдык көрүү: папкада `python -m http.server 8123` жазып, `http://localhost:8123` ачыңыз.
